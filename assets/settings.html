    Connect a phone

    Open the Yardbell app on your Android phone, tap Scan a pairing code and point it at the code. The phone signs in without the passcode. It must be on the same mesh VPN as this server.

    Each code works once, for five minutes. Get the app from the latest release.

    Phone notifications

    The Yardbell app for Android shows these while it is signed in to this server. Nothing else to install.

    Dispatch

    Open Dispatch

    Added to Dispatch's prompt for every conversation and followed before its own defaults. Use it for where your repositories live, which machine suits which work, branch naming, and anything you find yourself repeating.

    Each step shows up in the conversation as a card. When Dispatch asks, you can approve it, edit it first or reject it, and nothing runs until you approve.

    Dispatch runs Claude Code on this machine. The agent it starts can be any of yours.

    Agent tools (MCP)

    Let AI agents see your machines and sessions, and start, read and answer sessions, through an MCP server built into Yardbell.

    Add Yardbell to Claude Code on any machine on the mesh:

    The token lets an agent start and type into sessions on every machine. Keep it secret. Make a new one if it leaks: the old one stops working at once.

    MCP servers for sessions

    Claude Code sessions that Yardbell starts get these servers. Nothing is written on the machines: the list is passed when the session starts. Values, tokens included, are visible in that machine's process list while the session runs.
