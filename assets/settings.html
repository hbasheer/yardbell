    Agent tools (MCP)

    Add Yardbell to Claude Code on any machine on the mesh:

    The token lets an agent start and type into sessions on every machine. Keep it secret. Make a new one if it leaks: the old one stops working at once.

    MCP servers for sessions

    Claude Code sessions that Yardbell starts get these servers. Nothing is written on the machines: the list is passed when the session starts. Values, tokens included, are visible in that machine's process list while the session runs.
